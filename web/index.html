Wi-Fi Signal Strength Visualization System

An indoor Wi-Fi monitoring and network optimization platform designed for collecting, managing, and visualizing RSSI measurements over a structured indoor grid.

Academic Project Architecture

Android Application (Native WifiManager RSSI) ↓ [HTTP POST with Bearer JWT] Node.js / Express Server (Authentication, Validation, Timestamping) ↓ [Parameterized MySQL Queries] MySQL Database (Users, Measurements, Reports) ↑ [HTTP REST] Web Application (Dashboard, Dynamic Heatmap.js, Reports)

Note: Android and Web clients communicate strictly through the middle-tier Node.js REST API. No mobile client connects directly to MySQL.

Simple Android Mapper

Collects Wi-Fi RSSI automatically via native Android Wi-Fi APIs. The user selects a grid point (A1–E5) and presses MEASURE & SAVE with zero manual RSSI or timestamp entry.

Dynamic Heatmap

Generates interactive Wi-Fi coverage heatmaps dynamically using Heatmap.js over an indoor grid. Normalizes negative RSSI values to clearly pinpoint strong areas and dead zones.

Optimization Reports

Computes statistical coverage metrics, average signal strength, dead-zone warnings, and practical Access Point placement tips, with instant print and PDF export.
